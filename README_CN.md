# Uni TraeSkills

一个为 AI 编程助手打造的聚焦式技能库，围绕实用工作流程设计，而非泛泛的提示词堆砌。

## 项目概述

Uni TraeSkills 提供了一套精心策划的技能集合，引导 AI 编程助手按照结构化、可复现的工作流程完成任务——从需求分析到 UI 设计，全流程覆盖。每个技能都是自包含的，附带清晰的输入、交付物、参考资料和实用脚本，可轻松集成到任何 AI 驱动的开发环境中。

## 技能分类

### SDLC 开发流水线

四阶段开发流水线，将模糊的想法转化为可落地的代码：

| 技能 | 描述 |
|-------|-------------|
| **requirement-analyst** | 分析并澄清用户需求，产出结构化的 `REQUIREMENT.md` |
| **system-architect** | 将需求转化为技术架构与设计规格，产出 `DESIGN.md` |
| **task-planner** | 将设计规格拆解为可执行的开发任务，产出 `TODO.md` |
| **spec-coder** | 根据最终规格文档实现代码 |

### 设计与 UI

涵盖品牌标识、设计令牌和 UI 实现的综合设计智能系统：

| 技能 | 描述 |
|-------|-------------|
| **brand** | 品牌语调、视觉标识、信息框架和资源管理 |
| **design-system** | 令牌架构（原始 → 语义 → 组件）、CSS 变量、间距/排版比例与规格 |
| **design** | 元技能，根据任务类型路由到相应的设计子技能 |
| **ui-styling** | 基于 shadcn/ui 和 Tailwind CSS 构建美观、无障碍的界面 |
| **banner-design** | 社交媒体、广告和网站主视觉横幅的多方案生成 |
| **slides** | 基于 Chart.js、设计令牌和响应式布局的策略型 HTML 演示文稿 |

### 安全审查

面向 AI Agent 项目上线前的安全审查，覆盖模型服务、知识库、数据闭环和基础设施：

| 技能 | 描述 |
|-------|-------------|
| **agent-security-reviewer** | 上线部署前全面安全审查，覆盖 10 大安全域：模型与推理服务安全、RAGFlow 知识库安全、微调数据闭环治理、应用安全（OWASP LLM Top 10）、身份认证与访问控制、数据安全与隐私、日志与监控、供应链与依赖安全、基础设施加固、合规与安全治理。产出结构化 `SECURITY_REVIEW_REPORT.md`，含风险评级与可落地的修复建议。 |

### 设计依赖链

```
brand（品牌色彩、字体）
    ↓
design-system（令牌、规格）
    ↓
ui-styling（组件）
    ↓
应用代码
```

## 核心特性

- **面向工作流**：技能围绕实际开发流水线组织，而非泛化的模板
- **自包含单元**：每个技能包含参考文档、脚本、模板和结构化数据
- **丰富的设计智能**：涵盖 67+ 种 UI 风格、161 套色彩方案、57 组字体搭配、99 条 UX 指南，覆盖 16 种技术栈
- **跨平台兼容**：提供 20+ AI 编程平台的适配模板（Cursor、Copilot、Codex、Claude、Gemini、Windsurf 等）
- **Agent 安全**：内置安全审查技能，用于 AI Agent 部署前的安全审计
